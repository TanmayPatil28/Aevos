# Contributing to GradeFlow

We love your input! We want to make contributing to GradeFlow as easy and transparent as possible.

## Pull Requests

1. Fork the repo and create your branch from `main`.
2. Install dependencies: `npm install`.
3. If you've added code that should be tested, add tests.
4. Ensure the test suite passes (`npm run verify`).
5. Ensure your code lints and is formatted correctly (`npm run format`).

## Development Environment

Check out [DEV_ENVIRONMENT.md](DEV_ENVIRONMENT.md) for full details on setting up your local workspace.
