# Screenshot Guide for Aevos README

Place the following screenshots in this directory (`docs/assets/`):

## Required Screenshots

### 1. `aevos-banner.png` (Hero Banner)
- **Dimensions**: 1920x400 or similar wide aspect ratio
- **Content**: A sleek banner with the Aevos logo, tagline, and a subtle dark gradient background
- **Style**: Dark theme, minimal, professional (think Cal.com or Supabase banner)

### 2. `hero-screenshot.png` (Product Screenshot)
- **Dimensions**: 1440x900 or similar desktop aspect ratio
- **Content**: The main dashboard of Aevos showing the OS overview or calculator page
- **Style**: Full application screenshot with the sidebar visible, showing real data (not empty state)

## Optional Screenshots (for a carousel or features section)

### 3. `calculator.png` — SGPA/CGPA Calculator page
### 4. `attendance.png` — Attendance tracker with risk heatmap
### 5. `career-os.png` — Career Intelligence dashboard
### 6. `jarvis.png` — Dynamic Island with Jarvis assistant active
### 7. `placement.png` — Placement predictor eligibility matrix
### 8. `forecast.png` — AI forecast engine results

## Tips for Screenshots
- Use the live deployment at `aevos-gamma.vercel.app`
- Take screenshots on a high-DPI display (Retina/4K) for crisp rendering
- Use browser developer tools to set viewport to 1440x900
- Hide bookmarks bar and browser chrome for clean captures
- Dark mode is preferred (matches the README aesthetic)
