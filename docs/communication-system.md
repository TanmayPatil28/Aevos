# GradeFlow OS — Communication System

This document defines the strict communication guidelines, tone parameters, and copywriting standards for GradeFlow OS. All future features, UI components, empty states, and alerts must adhere to this system.

## 1. Core Emotional Target
The product should feel like **a very smart, reliable academic companion**.
*   **Target Emotions:** Calm, focused, in control, confident, and reassured.
*   **Banned Emotions:** Panic, stress, overly motivational, cheesy, or robotic/technical.

## 2. The Apple/Linear Standard
*   **Short & Precise:** Keep messaging short. Use minimal explanation. No long onboarding paragraphs.
*   **Premium Clarity:** The language must be highly polished and direct. Don't use ten words when three will do.
*   **Maintain Confidence:** Preserve terms that communicate mathematical trust and predictive accuracy (e.g., "Always Accurate", "Predictive Integrity", "Precise Mapping").

## 3. Approved vs. Banned Terminology

### Banned Terminology (Too Technical/Robotic)
*   *Dynamic State Mutation*
*   *Regulatory Parity Engine*
*   *Algorithmic State Derivatives*
*   *Edge Computation Latency*
*   *Combinatorial*
*   *Parser/Extraction/Ingestion*
*   *Command Center*
*   *Failure / Critical Emergency*

### Approved Terminology (Human but Intelligent)
*   *Plan with Confidence*
*   *Always Accurate*
*   *Instant Scenarios*
*   *Predictive Accuracy*
*   *Real-time Updates*
*   *Your Dashboard*
*   *Get Back on Track*
*   *Academic Records*

## 4. Empty State Philosophy
Empty states should guide, not lecture.
*   **Rule 1:** Must be short and actionable.
*   **Rule 2:** Must build confidence.
*   **Rule 3:** No long onboarding essays or excessive hand-holding.
*   *Example Good:* "Your Sandbox is empty. Add a course to test different grade scenarios safely."
*   *Example Bad:* "Welcome to the sandbox environment. Here you can ingest courses and perform dynamic state mutations..."

## 5. Alert & Messaging Standards
*   **Never Stress the User:** Do not use "Critical Error", "Failure", or "Emergency".
*   **Be Solution-Oriented:** If a student has backlogs, say "Let's get back on track" instead of "Your academic health requires immediate attention."

## 6. CTA (Call to Action) Standards
*   Use clear, action-oriented verbs.
*   *Examples:* "Save Scenario", "View Next Steps", "Explore Options", "Import Grades".
